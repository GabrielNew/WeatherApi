# Weather App

Basically this project may help you to identify the climate conditions in your city or any other place you are curious.

![](https://github.com/GabrielNew/WeatherApi/blob/main/images/Animation.gif)

## Built With

* [REACT](https://react.dev/) - The front end library used
* [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) - Back end
* [WEATHERAPI](https://www.weatherapi.com/) - A free api to get data about climate and the cities in the search
